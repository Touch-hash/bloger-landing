# Blogr Landing Page

A responsive landing page for a modern publishing platform, built from scratch using HTML, CSS, and Vanilla JavaScript.

The project focuses on building a responsive layout, implementing navigation dropdowns, and creating a mobile navigation menu using pure JavaScript without any frontend framework.

## ✨ Features

- Responsive landing page design
- Desktop and mobile navigation
- Dropdown menus for:
  - Product
  - Company
  - Connect
- Mobile hamburger menu
- Responsive layout across different screen sizes
- Interactive navigation using Vanilla JavaScript
- Custom styling with CSS
- Font Awesome icons
- Google Fonts integration
- Responsive illustrations and background graphics
- Semantic HTML structure

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (Vanilla JS)
- Font Awesome
- Google Fonts
- SVG illustrations

📱 Responsive Design

The page is designed to adapt to different screen sizes using CSS media queries.

The layout changes between desktop and mobile views, including:

Desktop navigation
Mobile hamburger menu
Responsive typography
Responsive content sections
Mobile-specific illustrations
Flexible section layouts
⚙️ JavaScript Functionality

JavaScript is used to control the interactive navigation elements.

The implementation includes:

Opening and closing dropdown menus
Handling Product, Company, and Connect menus
Toggling the mobile navigation menu
Switching navigation states depending on the screen layout

The project intentionally uses Vanilla JavaScript to practice DOM manipulation and event handling without relying on a framework.
